# Code and data availability statement

The Stata code used to prepare the analysis variables, reproduce the
statistical analyses, and generate the figures is available at https://doi.org/10.5281/zenodo.23294836. 
The analysis uses data from Wave 9 of the Survey of Health,
Ageing and Retirement in Europe (SHARE), release 9.0.0. SHARE microdata cannot
be redistributed with this repository. Researchers can apply for access and
download the data through the SHARE Research Data Center
(https://share-eric.eu/data/). The repository contains no individual-level
SHARE data; it contains code, documentation, and non-disclosive aggregate
outputs only.
